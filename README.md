## 1. 프로젝트 소개

OLA는 여러 기관에 흩어져 있는 생활안전 정보를 통합하고, AI를 활용해
사용자가 필요한 정보를 더 쉽게 확인하도록 돕는 지역 생활안전
플랫폼입니다.

재난·응급의료·범죄·생활민원 정보는 기관별로 제공되어 필요한 순간에
정보를 찾고 비교하는 데 시간이 걸릴 수 있습니다. OLA는 이러한 정보
접근의 불편을 줄이기 위해 공공데이터, 위치 기반 정보, AI 상담 및 이미지
분류 기능을 하나의 서비스로 연결했습니다.

단순한 정보 제공을 넘어, 사용자의 질문에 답하고 생활민원 사진을 분류해
신고 초안을 작성하는 등 정보 확인 이후의 행동까지 지원하는 것을 목표로
합니다.

## 2. 해결하고자 한 문제

-   **정보의 분산:** 기상·재난·응급의료·환경·민원 정보가 여러 기관과
    사이트에 나뉘어 있습니다.
-   **정보 탐색의 어려움:** 사용자는 자신의 위치와 상황에 맞는 정보를
    직접 찾아야 합니다.
-   **답변 신뢰성:** 일반 생성형 AI의 답변은 출처나 최신성이 명확하지
    않을 수 있어 안전 분야에 그대로 적용하기 어렵습니다.
-   **민원 작성의 번거로움:** 생활 속 불편 사항을 신고하려면 유형을
    판단하고 신고 내용을 직접 작성해야 합니다.

OLA는 공신력 있는 정보의 통합, 출처 중심의 AI 응답, 사진 기반 민원
분류를 통해 이러한 문제를 개선하고자 합니다.

## 3. 주요 기능

### 🛡️ 오늘의 OLA 브리핑

-   지역의 생활안전 정보를 한 화면에서 확인
-   날씨 및 대기질, 재난 위험, 응급실 관련 정보 등 주요 안전 지표 제공
-   정보의 출처와 기준 시각을 확인할 수 있도록 구성

### 🗺️ 안심·비상 시설 지도

-   사용자 위치를 중심으로 주변 안전·편의 시설 확인
-   병원, 약국, AED, CCTV, 여성안심길, 지구대·파출소 등 시설 정보 제공
-   주변 시설을 지도에서 확인할 수 있도록 구성

### 🤖 AI 생활상담

-   생활안전·응급·재난·민원 관련 질문 지원
-   지식베이스에서 관련 정보를 먼저 검색하고 필요한 경우 생성형 AI 활용
-   근거가 부족하거나 조회에 실패한 경우 임의로 단정하지 않고 공식 기관
    확인 안내

### 📷 사진 기반 생활민원 분류

-   사진을 분석해 보행방해물, 불법주정차, 현수막 등 민원 유형 분류
-   분류 결과를 바탕으로 신고 초안 작성 지원
-   실제 신고는 안전신문고 등 공식 신고 채널에서 진행하도록 연결

### 🔎 차량번호 인식

-   불법주정차 사진에서 차량번호 인식
-   인식 결과를 입력란에 반영하고 사용자가 수정할 수 있도록 지원
-   인식이 어려운 경우 번호판 영역을 지정해 다시 인식할 수 있도록 구성

### 🎙️ 음성 검색 및 다국어 지원

-   브라우저 음성 인식을 통한 질문 입력
-   한국어·영어·중국어·일본어 지원을 고려한 다국어 UI

### 💬 지역 커뮤니티 및 알림

-   지역 안전·생활 정보 공유를 위한 커뮤니티 화면
-   공식 알림과 지역 소식을 구분해 확인할 수 있도록 구성

## 5. 이미지 분류 모델 검증

생활민원 사진 분류 기능을 구현하기 위해 ResNet18 전이학습 모델과 직접
설계한 CNN 모델을 학습하고 성능을 비교했습니다.

  모델                  검증 정확도 적용
  ------------------- ------------- -----------
  ResNet18 전이학습           93.1% 기본 모델
  직접 설계 CNN               86.3% 비교 모델

검증 데이터 기준 ResNet18의 정확도가 더 높아 기본 모델로 선택했습니다.
학습된 모델은 ONNX 형식으로 변환해 브라우저에서 실행하도록 구성했습니다.

> 위 수치는 프로젝트의 검증 데이터에 대한 결과이며, 실제 현장 환경
> 전체에서의 분류 성능을 보장하는 수치는 아닙니다.

## 6. 정보 출처 및 데이터 연계

프로젝트에서 활용한 주요 정보 출처 및 연계 대상은 다음과 같습니다.

-   기상청: 기상특보·예보 등 기상 정보
-   국립중앙의료원: 응급의료 관련 정보
-   한국환경공단: 에어코리아 대기질 정보
-   국민권익위원회: 민원 관련 정보
-   경찰청: 범죄 통계
-   국민재난안전포털: 재난 행동요령 및 안전 정보
-   공공데이터: 대피시설 및 기타 생활안전 정보

각 데이터의 제공 범위와 갱신 주기는 원천 기관 및 API 제공 조건에
따릅니다. 서비스 이용 시 화면에 표시되는 기준 시각과 공식 출처를 함께
확인해야 합니다.

## 9. 실행 및 이용 안내

### 온라인 데모

별도의 설치 없이 아래 링크에서 배포된 웹 화면을 확인할 수 있습니다.

https://mylogspace.github.io/OLA/

### 로컬 실행

저장소를 내려받은 후 프로젝트의 프론트엔드 파일과 서버 구성을 확인해
실행합니다.

``` bash
git clone https://github.com/MyLogSpace/OLA.git
cd OLA
```

백엔드 기능을 로컬에서 실행하려면 `server/` 디렉터리의 실행 안내와
환경설정 예시를 확인하고, 필요한 Python 패키지 및 API 키를 설정해야
합니다.

-   API 키는 소스코드에 직접 입력하거나 공개 저장소에 커밋하지 않습니다.
-   서버 기능에 필요한 환경변수는 로컬 환경에서 별도로 설정합니다.
-   GitHub Pages 데모는 배포된 정적 웹 화면을 확인하기 위한 경로이며,
    서버·API 키가 필요한 기능은 별도 백엔드 설정에 따라 동작 범위가
    달라질 수 있습니다.

## 12. 유의사항

-   OLA는 생활안전 정보 확인을 돕는 서비스이며, 긴급 상황에서는 112·119
    등 공식 긴급 신고 및 대응 체계를 우선 이용해야 합니다.
-   AI가 제공하는 정보는 참고용으로 활용하고, 중요한 안전 판단은 해당
    기관의 최신 공식 안내를 확인해야 합니다.
-   실제 민원 접수는 안전신문고 등 해당 기관의 공식 채널에서 진행해야
    합니다.
-   공공데이터와 외부 라이브러리의 이용 조건은 각 제공 기관 및
    프로젝트별 라이선스를 따릅니다.
